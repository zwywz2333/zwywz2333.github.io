# 张文砚作品集网站

使用作品集 PDF 的讲述顺序和拆分素材制作的静态网站。封面的月球、猫群、轨道标记与文字分层呈现；素材载入完成后点击“进入档案”，转场至四项目录；每个项目有独立的详情页。

## 本地预览

在本目录运行：

```powershell
python tools/serve.py --port 4175
```

访问 <http://127.0.0.1:4175/>。封面进度条用约 1.5 秒完成动画，素材在后台继续预载；其后三颗四芒星依次对应读取、权限验证和进入。加载文字与百分数位于画面中心，进度线横贯视口；验证后文字与百分数柔和左移，右侧进入按钮接续显现，三颗星始终保持页面居中。封面参考原 PDF 第 1 页，目录使用你提供的 4 张独立档案卡图层重组原 PDF 第 3 页；每张卡片后的月球在悬浮或键盘聚焦时滑出，离开后收回。手机目录拆成两列。目录品牌下方的“返回入口”通往加载页。

项目页沿用原页的构图与信息，章节和章内图片均采用临近吸附，使滚动保持自然停靠。桌面项目图幅为上一版的约 80%，仍保持居中；手机图幅维持满宽阅读。图片查看器按需读取原始 PNG 或 PDF 导出的高清备用图；方向键、点击按钮、触摸滑动均可翻页。单页章节不显示无效翻页按钮。章节入口提供进度和可选设计线索，阅读内容无需解锁。Pacer 的基础规范与页面/组件结构合为一章；开化第 06 章按原图内容命名为“AR 打卡：地图定位与现场互动”。蓝、灰、青、紫的页面基色分别来自四个项目。

“关于我”页使用新拆分的高清图层，个人介绍与工作信息连贯排布；照片、文字、轨道随指针和滚动产生轻量分层视差，工作信息交错入场。手机端对工作与获奖信息另做可读文字排版。最新一页简历位于 `assets/resume.pdf`。介绍后和工作区均可进入独立微信二维码页；结尾采用原 PDF 第 60 页的 16:9 比例，并保留联系入口。

英文字体使用本机安装的 Clash Display Bold，中文大标题使用猴尊宋体，其余中文使用 HarmonyOS Sans SC。当前通过浏览器 `local()` 使用本机字体，发布时若希望所有访问者都看到相同字体，需要确认字体的网页分发许可，再将字体文件加入 `assets` 并改用 `@font-face url()`。

## 维护

- `data/projects.json` 保存原 PDF 页码、章节和项目说明。
- `tools/build_site.py` 生成所有 HTML。修改页面结构后执行 `python tools/build_site.py`。
- `archive-v9.css` 负责全宽进度线、月球收放、紧凑的关于页、联系按钮和二维码页；`archive-v8.css` 保留封面居中动效、关于页图层和柔和吸附；其余样式按版本逐层扩展。
- `archive.js` 负责载入、图片查看、章节导航和翻页。
- `assets/layers` 保存你拆出的封面、目录与关于页素材。封面光标使用 `crosshair-center.png` 与 CSS 轴线，保留完整的 `crosshair.png` 作为后续动效调整素材。
- `assets/full` 在本地保留 PDF 导出的备用图；`assets/portfolio-slides` 是上一版低分辨率预览留存，都不进入发布包。
- `assets/source-png` 已覆盖作品集全部 60 页。新增的第 11、31、39 页分别来自你补发的 `60.png`、`13.png`、`21.png`。映射见 `data/source-images.json`。
- `assets/wechat-qr-source.png` 是你提供的微信截图；网页只用 CSS 裁切二维码区域，不改动二维码像素。

`styles.css` 与 `script.js` 是旧版留存文件，不参与新版页面。不要直接修改生成的 HTML；重建会覆盖它们。
